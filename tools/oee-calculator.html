    How OEE is calculated

    OEE multiplies three ratios. Each one isolates a different kind of loss.

    Availability
    Run time divided by planned production time. Planned time is the shift minus planned breaks; run time is planned time minus unplanned stops, setups and waiting.
    Performance
    Ideal cycle time multiplied by total parts, divided by run time. It captures slow cycles and short stops while the machine is nominally running.
    Quality
    Good parts divided by total parts. Scrap and rework both count as losses, because they used machine time.
    OEE
    Availability × performance × quality, which equals good parts multiplied by ideal cycle time, divided by planned production time.
    Where to use it
    On the constraint first. Raising OEE on a machine with spare capacity doesn't increase the shop's output. See how to find the real bottleneck.
